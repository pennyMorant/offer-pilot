# Prop 22 报价情景估算

## 官方口径与版本

核对日期：2026-11-02。

- [加州财政厅](https://www.treasurer.ca.gov/prop-22)：2026 年有效机动车里程费率为 $0.37/英里，年度费率会更新。
- [加州劳工部门](https://www.dir.ca.gov/dlse/minimum_wage.htm)：2026 州最低时薪为 $16.90；部分城市/县更高。
- [Uber 保底说明](https://help.uber.com/en/driving-and-delivering/article/node-title?nodeId=66f150ee-bb9c-4d4d-89e8-54048db45a35)：有效时间为接单至完成，空等不算；时间保底按适用最低时薪的 120% 计算，小费排除，按两周周期比较符合口径的平台收入后补差。
- [DoorDash Prop 22 指南](https://help.doordash.com/en-us/dashers/article/california-dashers)：加州取餐订单适用，按取餐地最低时薪和有效机动车里程计算，按周核对平台收入，小费不冲抵保底。

本功能不处理医疗津贴、税费或实际结算。使用报价总耗时/总里程作为有效时间/里程的近似，不能将报价预计时间视作最终计费时间。

## 使用与公式

规则页 → Prop 22 额外收入估算 → 启用 → 设置取餐地适用最低时薪、机动车开关和假设小费比例 → 保存全部接单要求。两个平台共用设置，不随平台编辑范围切换而丢失草稿。保存后按原规则关闭自动接单意愿。

默认关闭，最低时薪默认 $16.90，机动车默认开启，小费假设默认 0%。没有自动识别加州边界或城市最低时薪；跨城市工作需用户更新设置。0% 只代表把整笔报价当作平台收入计算，不代表真实没有小费。其他奖金或收入并不由此报价画面完整呈现。

设报价为 Q，假设小费占比为 p，总耗时为 T 小时，总里程为 M 英里，取餐地最低时薪为 W：

```text
时间保底参考 = T × W × 1.2
里程保底参考 = M × $0.37（非机动车为 0）
保底参考 G = 时间保底参考 + 里程保底参考
假设小费 = Q × p
假设平台收入 B = Q − 假设小费
单单情景额外补差 = max(0, G − B)
报价加情景补差 = Q + 单单情景额外补差
```

例如报价 $8、总耗时 30 分钟、总里程 5 英里、最低时薪 $16.90、机动车、小费假设 25%：保底参考 $11.99；假设小费 $2、平台收入 $6；单单情景补差 $5.99，报价加情景补差 $13.99。这是公式说明，不是真实平台订单测试结果。

不能把 G 全额加到 Q 上，也不能把各单正差额相加当作法定应收款。平台在自己的结算周期比较总保底和符合口径的总收入，高于保底的订单可能抵消其他单的差额，实际额外到账可能为 0。Uber 与 DoorDash 的周期收入不能混在一起抵扣。

## 字段与存储边界

- 订单卡、悬浮窗、图片测试及文本预览展示相同的估算结果。
- 必须有可信总时间；机动车还需可信总里程。缺失时显示原因，不能填 0；金额未知时可显示保底，但不能估算补差。
- 非 USD、追加单、叠单暂不估算，避免重叠有效时间重复计入。
- 按识别时间的加州年份使用 2026 费率，其他年份停止估算。历史截图不自动推断拍摄日期，当前入口只适合当前年度场景。
- 小费始终是配置假设，不是 OCR 提取出的实际小费。OCR 来源限制保持不变。
- 只持久化全局开关和估算参数；不增加逐单数据、实际收入记录或周期应收表。
- 补差不进入自动接单门槛、车辆成本后贡献、历史质量评分或统计累计。

本轮静态审核并成功编译 Debug APK，未运行自动测试、模拟器或真实订单操作。
