# 临时节点诊断

入口：工作台 → 临时节点诊断。需要先开始工作并连接 Shevery；本功能用于手动适配真实平台页面，不自动接单。

## 使用步骤

1. 打开诊断后点击“5 秒后抓取”。
2. 在倒计时结束前切换到 Uber / DoorDash 的目标页面，保持屏幕解锁。
3. 抓取结束后返回 Overud，查看页面分类、节点列表与区域示意图。
4. 点击节点可在图中高亮其边界。默认隐藏文字；确实需要核对金额、地址等内容时，手动开启“显示节点文字”。
5. 点击“关闭并清空”，恢复普通采集；自动接单意愿保持关闭，需要重新手动开启。

图为节点几何示意，不是截图：灰色细框显示可见节点，辅色粗框显示 OCR 区域候选，主色粗框显示选中节点。无法定位区域时明确显示整屏回退候选，不伪造局部框。存在区域候选不保证截图/OCR 成功，实际还要检查显示屏及截图前后帧一致性。

节点列表显示索引与父索引、资源 ID、边界、可见/启用/可点击状态；页面摘要列出动作标签候选。候选仅按对应平台标签匹配，不代表满足实际点击条件：唯一性、父节点、报价字段、窗口和指令期限仍由真实接单流程复核。

## 隔离和生命周期

- 打开诊断关闭自动接单意愿，清理旧报价，普通采集暂不读取节点或记录报价。已有平台订单不会取消；已提交系统的动作不能靠打开诊断撤回。
- 进入和退出诊断均切换工作代次，避免旧采集或看门狗覆盖诊断后的状态。
- 只保留一份内存结果，重新抓取替换，关闭清空；没有写入数据库、磁盘、截图文件或日志，没有自动导出。手动选择文字复制属于用户操作。
- 原始节点只由新增手动 AIDL 方法返回，普通采集不传完整节点列表。限制 450 个节点、文字总量 30000 字符；资源 ID 与包名在诊断传输中各限制 256 字符。
- 应用范围最多一个诊断读取调用；读取超过 5 秒后忽略迟到结果，关闭界面也不接收旧结果。底层 Binder 阻塞无法被强制撤销，未返回前不会新增诊断读取。
- 工作结束、连接改变、设备锁定或切换到不支持应用时提示重新抓取。画面只代表抓取时刻，不是实时监视。

当前源码 UserService 为 v6。按用户要求，本轮未编译、未运行测试或设备操作，现有 APK 不含此入口。已做调用点、节点容量、状态隔离、关闭清理和文件行数静态审核。
