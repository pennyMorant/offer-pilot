# 车辆成本与时薪口径

## 当前实现

每英里车辆成本使用规则页配置，公共要求和平台独立要求分别保存。可配置为 0，负数无效；不会自动查询油价、税务标准或实际车辆支出。

对于 USD 报价，在金额已确认、总路线口径明确时计算：

```text
车辆成本估算 = 总里程（英里） × 配置的每英里车辆成本
扣成本贡献估算 = 显示报价 − 车辆成本估算
毛时薪 = 显示报价 × 3600 / 报价总耗时（秒）
扣车辆成本后时薪 = 扣成本贡献估算 × 3600 / 报价总耗时（秒）
```

报价使用整数美分，估计值使用 Double，仅展示时保留两位小数；阈值比较使用未显示舍入的值，保留现有浮点边界容差。负贡献保留负数，不截成 0。没有可信总里程时，成本和贡献未知；没有可信总耗时时，相应时薪未知。追加单缺少明确增量路线口径时不生成整单效率估计。

这些估计只覆盖报价路线及配置成本，不包含未来等待、重新定位、回程、停车费、过路费或税费。不会把报价当作实际结算，也不称作净利润或完整配送周期时薪。未来等待观测的完成样本均值不直接并入本计算。

## 自动接单

最低时薪条件可选择“报价毛时薪”或“扣配置车辆成本后时薪”。阈值仍为 USD/小时，默认及旧配置均使用毛时薪，不自动改变已有接单行为。

启用成本后时薪条件时，可信金额、总里程、总耗时和有效成本配置必须同时存在；未知不能通过门槛。关闭最低时薪条件后，该条件不参与自动接单，成本估算仍可展示。最低金额、每英里报价及其余启用条件仍按 AND 判断，至少保留一项最低收益要求。

公共要求、平台覆盖、继承、草稿切换、保存和点击前复核均传递时薪口径。保存时关闭自动接单，并立即按新版本刷新当前报价判断；未保存草稿不影响工作卡片和规则预览。持久化枚举值无法识别时，关闭可执行平台，不静默把损坏值当作另一种接单口径。

## 展示与存储

订单卡片、悬浮窗和已保存规则预览显示车辆成本、扣成本贡献与成本后时薪。工作台的规则摘要显示实际选择的时薪口径及每英里成本。预览支持滚动，避免新增估算内容挤出操作区。

本轮只扩展偏好设置和内存 Valuation，没有修改 Room 数据库，没有保存逐单成本、地址、报价或收益记录。历史地区/时段质量仍按固定毛报价标准累计，用户改成本或时薪口径不会重算历史质量。

本阶段仅做静态审核，涵盖配置传递、旧配置兼容、来源/总量判断、负贡献、未知字段、保存后刷新、引用及文件行数；没有新增或运行测试，没有运行编译或模拟器。
