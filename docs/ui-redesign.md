# 界面重设计与版本隔离

## 支持范围及主题

最低 Android 13 / API 33；不变更 compileSdk 和 targetSdk。外观在设置页编辑，默认系统动态色 + 跟随系统明暗，也可关闭动态色并选择浅色或深色。偏好独立保存，修改即时发布，不修改接单规则。

Activity、系统栏和悬浮窗消费相同外观偏好。默认深色方案补齐容器前景色。统计分布条同时显示文字计数，订单状态同时显示原因，不能仅凭颜色判断。

## 信息结构

当前底部已进一步合并为工作台、区域分析、规则三个目的地；区域分析内切换区域机会和时段趋势，顶部进入设置。

- 工作台：连接异常时提示、工作控制、自动接单控制、当前订单。删除宣传大标题、90 天统计及测试按钮。报价、里程效率和时薪优先；车辆成本、Prop 22、目的地证据和完整理由收进详情。
- 区域分析：机会分析/配送表现切换，筛选放入底部面板；区域机会与时段趋势共享筛选状态。区域按机会指数、质量、频率或与当前网格的直线距离排序；证据不足和未知位置排在末尾。
- 规则：编辑范围 + 分组摘要，点击进入收益、距离时间、区域条件或偏好。固定保存栏、字段错误、当前草稿/已保存状态。切换范围保留草稿；离开页面须继续编辑或放弃修改。规则保存仍关闭自动接单意愿。
- 设置：外观、语音、Prop 22、连接与权限、版本说明。估算参数明确保存，其余外观和语音即时生效。

报价质量和新版配送观测均可按餐饮、包裹、未知类型筛选。旧配送观测保留为 UNKNOWN，不猜测回填订单类型。

## Debug 与 Release

图片识别页面、节点诊断页面、文本规则预览，以及对应专属 ViewModel 和手动图片读取器，移至 `app/src/debug/java`。开发工具只在 Debug 的设置中出现。

公共 ViewModel 工厂委托同名变体工厂。Release 实现不创建测试 ViewModel，设置入口实现为空；不靠运行时开关隐藏测试页面。原有实时 OCR、页面节点采集及正式用户权限诊断保留。

## 审核边界

本轮仅进行静态源码与引用检查、Git 差异空白检查和物理行数检查；没有编译、测试、模拟器、截图预览或设备安装。布局、系统栏及动态色的实际设备效果尚未运行确认。
