# 订单价值评分

## 结果分层

订单判断分为四层，不能只看最终分数：

1. 识别可信度：金额、总里程、总耗时必须来自同一张可靠的平台报价卡；OCR 结果只展示，不自动接单。
2. 硬条件：平台开关、报价时效、币种、最低收益、路线限制、商家/目的地排除和区域要求分别判断。
3. 经济价值分：只比较可配置车辆成本后的贡献，不使用 Prop 22 情景补差。
4. 目的地区域证据：独立显示历史报价质量；启用区域硬条件时才阻断自动接单，不伪装成下一单概率。

高分不代表一定自动接单。可信度不足或任一已启用硬条件失败，都不会执行接单动作。

## 经济口径

```text
车辆成本 = 平台显示的总路线英里 × 用户配置的每英里车辆成本
单笔贡献 = 平台显示报价 − 车辆成本
每英里贡献 = 单笔贡献 / 总路线英里
贡献时薪 = 单笔贡献 × 3600 / 有效预计耗时秒数
```

这些值不包含税费、停车费、过路费、送达后的等待和重新定位，因此是“成本后贡献估计”，不是净利润。

三个分项对用户目标做归一化：达到目标得到 70 分；从目标到目标的 1.5 倍线性增加至 100 分；超过 1.5 倍仍为 100 分。低于目标时从 0 到 70 线性计算。最终权重为：

- 贡献时薪 50%
- 每英里贡献 35%
- 单笔贡献 15%

最终等级：85–100 优秀、70–84 合格、50–69 临界、0–49 较差。默认自动接单最低价值分为 70，所有目标和最低分都可在规则页修改。

## 耗时校准

默认使用平台报价总耗时。应用只保存按平台、服务类型、收到报价地区、当地星期和小时聚合的配送观测，不保存逐单报价或路线。

同一范围至少有 20 个“报价耗时/完成实耗”配对样本时，按同小时、相邻小时、其他日期同小时、地区基线的顺序寻找可用聚合比例。有效比例限制在 0.5–3.0；实际评分使用平台耗时和聚合校准耗时中较长者，所以历史数据只能让判断更保守，不能提高订单评分。应用会显示当前使用的平台耗时或历史聚合校准耗时。

## 历史质量与实时分数

地区和时段统计使用固定的历史质量标准 v2，保证用户修改个人目标后历史趋势仍可比较：

- 优质：毛报价每英里至少 $2，且毛报价时薪至少 $25。
- 低价值：毛报价每英里低于 $1，或毛报价时薪低于 $15。
- 其他完整样本为普通；字段不足单列未知。

固定历史质量不使用报价绝对金额，也不使用车辆成本、个人目标、Prop 22 或目的地预测。实时价值分则反映当前个人目标，两者用途不同。
