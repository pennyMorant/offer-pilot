# 运行状态与权限

入口：工作台 → 运行状态与权限。无需进入节点诊断，不暂停普通采集；打开页面只读取状态，返回系统设置时刷新，也可手动刷新。

## 显示内容

- Shevery 是否连接、是否授权、特权采集进程是否绑定。
- 当前工作、自动接单、订单占用或节点诊断状态，以及已有工作提示。
- 本进程最近一次读取支持平台的时间；不把此时间当成当前报价识别成功证据。
- 屏幕是否可交互、设备是否锁定。
- 应用通知开关和工作通知渠道；渠道还未创建时不会宣称已经成功显示通知。
- 通知读取权限，与应用自身通知显示权限分开。
- 悬浮窗、精确/大致定位权限和系统定位总开关。
- 系统电池优化豁免及标准后台限制状态。

连接和工作状态由已有 StateFlow 更新，系统设置在打开、返回及手动刷新时查询。读取失败显示未知，不默认当成已授权。

## 设置与边界

点击按钮才进入对应系统设置；Shevery 按钮执行已有检查/授权流程，授权仍由系统确认。定位按钮使用现有运行时权限申请。电池按钮打开优化设置列表，不自动申请豁免、不修改电量策略；设置无法打开时给出手动查找提示。

不使用“一键全授权”，不新增麦克风、后台定位、广泛文件访问等权限。悬浮窗或通知读取未授权并不等于核心解析必然不可用，界面分别解释其影响。位置权限改变后仍需重新开始工作。

绑定状态不证明每个订单页面都已适配；标准电池状态不证明应用不会被清理。厂商自启动、省电和后台锁定策略无法统一检测，需按设备自行设置。刷新时若发现 Shevery 连接失效，原有安全逻辑仍会关闭自动接单意愿。

本轮只做静态审核，不编译、不运行测试或设备操作。现有 APK 未更新，不包含此入口。
