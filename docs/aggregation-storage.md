# 汇总存储与报价质量分析

## 数据流程

识别报价 → 内存 Offer → 提取 QualitySample → 判断质量 → 按平台/地区/小时归组 → 更新累计统计。

自动接单是否开启、报价是否被接下，不影响有效报价进入统计。金额无法确定时不计为有效报价；缺少可信总里程或总耗时的报价计入“信息不足”。

不保存逐单报价、原始界面文本、完整地址、截图或 GPS 轨迹。最新报价在工作期间短暂展示，结束工作时清空；内存中每个平台最多保留当前报价及其统计贡献。

## 数据库结构与容量边界

| 表 | 粒度 | 内容 |
| --- | --- | --- |
| hourly_quality | 平台 × 类型 × 地区 × 当地小时起点 × 时区 × 质量版本 | 数量、累计值、样本数、质量计数和区间分布 |
| delivery_aggregate | 平台 × 类型 × 地区 × 当地小时起点 × 时区 × 观测版本 | 完成/中断次数及报价耗时与完成实耗配对累计 |
| region_exposure | 平台 × 网格 × 小时 | 采集覆盖时间代理 |
| statistics_checkpoint | 每平台最多一行 | 最近一次已统计报价的不透明指纹和过期时间 |
| acceptance_state | 全局一个 active 槽位 | 指纹、平台、规则版本、动作状态、简短结果码 |

汇总与覆盖时间保留最近 90 天，在启动及工作期间按日清理过期分组；指纹检查点固定容量。SharedPreferences 中每平台只保存一个短时指纹与时间戳，用于重启后的报价身份衔接，不含金额或地址。

## 指标与版本

每个分组分别保存：报价总数、优质/普通/低价值/未知数量、OCR 样本数，金额/距离/耗时的累计值及有效样本数，每英里报价和预估毛时薪的累计值及有效样本数。

金额、每英里报价、预估毛时薪还各保存六个区间的计数，以定长字符串存储。区间累计支持后续近似分位分析，当前页面不展示精确中位数。

质量标准 v2 独立于自动接单开关和个人阈值：

- 优质：每英里至少 $2、预估毛时薪至少 $25，全部满足。
- 低价值：完整样本中，每英里低于 $1、毛时薪低于 $15，任意满足。
- 普通：其余完整样本。
- 信息不足：缺少可信金额、总里程或总耗时，不能完成分类。

均值按相应指标的有效样本数计算，不以全部报价数作分母。优质比例仅对可分类样本计算，少于 10 张时不输出倾向比例。金额为报价、时薪为估计毛收入，不代表实际结算。

历史评价标准变化时创建新版本，分开统计。没有逐单明细后，不能按任意新阈值精确重算旧历史；仅可使用已保存的累计值和区间信息进行有限近似分析。

## 地区与时间

持久化的地区表示收到报价时的司机位置网格。位置缺失单列 UNKNOWN。目的地在内存临时解析为网格后，可查询相应地区的收单质量历史，但不把这两种位置语义混为一谈，也不将完整地址写入汇总表。

每小时分组使用报价首次观察时间、当地时区和小时起点，保存当地日期、星期和小时。夏令时重复小时具有不同实际起点；半小时时区按当地整点划分。页面将多个日期按相同星期/小时汇总，并将不同时区或质量版本分开。

统一的区域分析页可在“区域机会”和“时段趋势”之间切换。时段趋势可选择地区；区域机会在相同平台、类型、星期和时段下比较网格。数据只描述本机观察到的报价，不代表全市场订单。

## 去重与修订

- 同一持续可见报价重复采集时只统计一次。
- 当前报价字段补全或价格更新时，在事务中撤销旧贡献、加入新贡献，报价数不重复增加。
- 地区最初未知、随后得到位置时，可将当前报价贡献移动到该地区；已经确定的收到报价位置不随司机移动改变。
- 只在内存为统计保留同一报价的已确认特征；这些特征绝不回填自动接单判断，自动动作仍以最新页面为准。
- 重启后检查点可以抑制当前报价重复计数；由于没有保存该报价的旧特征，重启前的报价后续修订不追溯更正。
- 缺少平台报价 ID 时依赖短时指纹及页面变化，连续相同报价若未观察到消失可能合并；进程异常或识别缺失也可能影响计数。统计不是平台官方账单。

## 开发阶段数据库策略

当前不维护 Room 历史迁移链。schema 版本不匹配时销毁数据库并按当前 Entity 重建，不转换或保留旧统计、等待、配送及接单恢复状态。该策略仅适用于尚未发布的开发阶段；发布前必须移除 destructive fallback，并从首个发布 schema 开始维护迁移。

## 实施边界

后续代码仍仅做静态源代码审核，没有编译、测试或模拟器。已加入临时目的地网格评估、配送状态、等待及完成耗时汇总，实际收入结算尚未接入。当前数据库 schema 版本为 6，仅表示开发 schema 修订号，不提供旧版本兼容。所有汇总继续独立保存有效样本数并保留 90 天，不保存逐单结果。
